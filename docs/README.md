# Docs

- `design/` - image prompt briefs for the landing page and the app.
- `reports/cleanup-deployment/` - record of the last production deployment and its checks.
- `reports/project-audit/` - audit output, including generated logs and screenshots. Regenerated by `scripts/audit-source.cjs`; do not edit by hand.
- `reports/youpeak-icon-prompts/` - icon prompt pack, generated by `scripts/build-icon-prompt-pack.cjs`.
- `reports/apk-size/` and `reports/desktop-layout/` - one-off size and layout checks.
