# Docs

All reports, notes, and design material for the repository. Nothing in this folder is used by the apps at runtime.

- `notes/` - working notes: admin panel documentation, Flutter prompt notes, and landing prompt notes.
- `design/` - image prompt briefs for the landing page and the app.
- `reports/cleanup-deployment/` - record of the last production deployment and its checks.
- `reports/project-audit/` - audit output, including logs and screenshots. Regenerated by `scripts/audit-source.cjs`; do not edit by hand.
- `reports/youpeak-icon-prompts/` - icon prompt pack, generated by `scripts/build-icon-prompt-pack.cjs`.
- `reports/apk-size/` and `reports/desktop-layout/` - one-off size and layout checks.
