[PAGE 01] /admin/mainDashboard (Dashboard.js)
----------------------------------------------------------------------------------------------------
- Features: Real-time analytics, user growth chart, video uploads, shorts count, active users.
- Forms/Filters: DateRangePicker ("All", 7-day, 30-day, custom dates).
- BUG DETECTED [SEVERITY: HIGH - DATA CORRUPTION]:
  In lines 87-126, date labels from `chartAnalyticOfUsers`, `chartAnalyticOfVideos`, and 
  `chartAnalyticOfShorts` are pushed into `label` and then deduplicated and sorted. However, the data 
  arrays `dataUser`, `dataVideo`, `dataShort` are pushed in raw response order and NOT aligned to the 
  sorted `label` array! If User data has dates [D1, D3] and Video data has [D2], Video count for D2 is 
  displayed at position 0 (which is D1), completely shifting and corrupting data curves.
- CORRECTION:
  Replace raw array pushing with a `Map<DateString, Number>` lookup:
  ```javascript
  const userMap = new Map(chartAnalyticOfUsers?.map(i => [i._id, i.count || 0]));
  const videoMap = new Map(chartAnalyticOfVideos?.map(i => [i._id, i.count || 0]));
  const shortMap = new Map(chartAnalyticOfShorts?.map(i => [i._id, i.count || 0]));
  const alignedUser = label.map(d => userMap.get(d) || 0);
  const alignedVideo = label.map(d => videoMap.get(d) || 0);
  const alignedShort = label.map(d => shortMap.get(d) || 0);
  ```

3. BACKEND API & ARCHITECTURAL VULNERABILITY AUDIT
====================================================================================================

3.1. Language Controller Default Inconsistency (language.controller.js)
----------------------------------------------------------------------------------------------------
- Location: `functions/backend/controllers/admin/language.controller.js` line 118:
  ```javascript
  if (Number(toggleType) === 2) updateData.isDefault = true;
  ```
- Vulnerability:
  When an admin marks a language as default, the backend marks `isDefault = true` on that document, 
  but does NOT unset `isDefault = false` on previously existing default languages! Over time, multiple 
  languages have `isDefault: true`, leading to indeterminate default language selection in the mobile client.
- Fix:
  Before setting `isDefault = true`, execute a batch update setting `isDefault = false` across all other languages.

3.2. Unbounded Collection Scans in Digital Partner Reporting
----------------------------------------------------------------------------------------------------
- Location: `functions/backend/controllers/admin/digitalPartner.controller.js` line 158-159:
  ```javascript
  db.find("referralHistories", {})
  db.find("localBusinessAds", {})
  ```
- Vulnerability:
  When generating reports, if there is at least one partner, the controller queries the ENTIRE table of 
  referrals and local business ads without a filter or date range. As the user base scales to 100,000+ 
  referrals, this will cause memory spikes (OOM) and cloud function execution timeouts.
- Recommendation:
  Filter by `referrerId: { $in: partnerIds }` and period date boundaries.

3.3. Payment Webhook Verification Idempotency
----------------------------------------------------------------------------------------------------
- Location: `functions/backend/controllers/client/payment.controller.js`
- Audit:
  Razorpay webhook signature verification is implemented correctly using SHA256 HMAC.
  Idempotency check prevents double-crediting if Razorpay retries webhook delivery.

4. ANDROID / FLUTTER CLIENT APPLICATION AUDIT
====================================================================================================

----------------------------------------------------------------------------------------------------
4.1. CRITICAL STARTUP / LIVE STREAM CRASH: Constant.appId FormatException
----------------------------------------------------------------------------------------------------
- File: `youpeak/lib/utils/constant/app_constant.dart` line 150:
  ```dart
  static int appId = int.parse(AdminSettingsApi.adminSettingsModel?.setting?.zegoAppId.toString() ?? "");
  ```
- Root Cause:
  Dart initializes static variables upon first class access. When `Constant` is accessed during app launch, 
  `AdminSettingsApi.adminSettingsModel` is null because settings have not finished downloading from the network.
  The expression falls back to `""` (empty string).
  Calling `int.parse("")` throws an immediate, unhandled `FormatException: Invalid number (at character 1)`.
  When `createEngine()` runs in `main.dart` (line 336), this crash takes down the entire application or prevents 
  the broadcast engine from initializing.
- Correction:
  Change line 150 to use `int.tryParse`:
  ```dart
  static int get appId => int.tryParse(AdminSettingsApi.adminSettingsModel?.setting?.zegoAppId?.toString() ?? "") ?? 0;
  static String get appSign => AdminSettingsApi.adminSettingsModel?.setting?.zegoAppSignIn ?? "";
  ```

----------------------------------------------------------------------------------------------------
4.2. GUEST & UNAUTHENTICATED CRASH: Unsafe Bang Operator on Database.loginUserId!
----------------------------------------------------------------------------------------------------
- Files Affected:
  - `youpeak/lib/pages/video_details_page/normal_video_details_controller.dart` lines 1032, 1059, 1105
  - `youpeak/lib/pages/video_details_page/shorts_video_details_view.dart` lines 88, 110, 333, 407
- Root Cause:
  When a user opens the app without logging in (or follows a shared deep link to watch a video as a guest), 
  `Database.loginUserId` is NULL.
  The code calls:
  `videoDetailsModel = await VideoDetailsApi.callApi(Database.loginUserId!, videoId, 1);`
  The `!` operator throws: `Null check operator used on a null value`, completely crashing the video player screen!
- Correction:
  Safely coalesce `Database.loginUserId`:
  `Database.loginUserId ?? ""`

6. ROLE-BASED ACCESS CONTROL (RBAC) MATRIX AUDIT
====================================================================================================
The project defines 3 administrative roles:
1. SUPER_ADMIN: Full access to all 37 routes, global platform configs, financial payouts, and franchise licensing.
2. AGENCY_ADMIN (District Franchise): Access restricted to `agencyDashboard` and `agencyReports`. Cannot view or modify global system settings, other districts, or global platform users. Scoped strictly via `req.agencyId`.
3. DIGITAL_PARTNER_ADMIN: Access restricted to `partnerDashboard`, `partnerLocalBusinessAds`, and `digitalPartnerReports`. Cannot view other partners or administrative settings. Scoped strictly via `req.partnerUserId`.

RBAC Security Assessment:
- Frontend Sidebar properly isolates navigation arrays via `isAgencyAdmin` and `isDigitalPartnerAdmin`.
- Backend `checkScope.middleware.js` enforces scope derivations for all `/admin/*` routes.
- Unauthorized cross-tenant data access attempts return HTTP 403 Forbidden.
